# 基板改修情報

Rev.6以前の基板をRev.7相当の回路に改修するための情報です。
Rev.6以前の基板はMSX本体に負担を掛ける回路でしたので、この改修を行うことを強く推奨します。
<br>これにより、回路はRev.7と同等になり、本体への負担軽減のほか、電池保ちが改善され、互換性が向上します。

なお、実際の改修はRev.4～Rev.6の基板で検証しています。Rev.3以前の基板の場合は、同じ手順で改修出来ない可能性があります。

## 改修手順

実際の改修手順です。

1. パターンカット 基板表面
<br>パターンカットを行います。
<br>画像の赤線(2ヶ所)のパターンをカットします。

![](cut_front.png)

2. パターンカットと部品撤去 基板裏面
<br>表面と同様にパターンカットと、加えてD1、D2、R3、R4の撤去を行います。
<br>画像の赤線(7ヶ所)のパターンをカットし、橙線で囲われている部品を外します。

![](cut_back.png)

3. 部品取付とジャンパ配線 基板裏面
<br>以下の実体配線図をもとに部品を載せて、配線材でジャンパを飛ばします。
<br>R3、R4はダイオードBAT43(向きは画像を参照)に換装、D2も同じくBAT43(向きは元と同じ)に換装、D1には部品は載せず配線で繋いでバイパスします。
<br>100pFの積層セラミックコンデンサは、元R3の場所に載せたBAT43と並列になるように繋ぎます。
<br>47μFの電解コンデンサは、マイナス側を元D1のカソード(GND)に、プラス側をD2のカソードに繋ぎます。R3・R4付近の横のラインにはケース内側の凸部が来るので、電解コンデンサを置いてしまうとケースが閉まらなくなる可能性がありますのでご注意ください。

![](patch_back.png)
